# 台股分析與觀察工具

本儲存庫保留原有的市場分析與券商 API 程式，並新增一個以 Streamlit 執行的研究介面 `app.py`。

## 啟動研究介面

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

預設標的是台積電 `2330.TW`。上市代號通常使用 `.TW`，上櫃代號通常使用 `.TWO`。

## 研究介面功能

- 個股日、週、月 K 線與均線、成交量、MACD、RSI、KD、布林通道
- 規則辨識常見 K 線型態（鎚子、流星、吞噬、母子、貫穿／烏雲、晨星／夜星、十字線），可在圖表標記並納入觀察清單篩選
- 與加權指數、櫃買指數比較區間績效
- Yahoo Finance 可提供的估值、公司概況與新聞
- 證交所／櫃買中心最新三大法人買賣超
- 可選載入近 5 個交易日 5 分鐘 K 線，估算偏買／偏賣量
- 自訂觀察清單快速掃描
- 資料缺漏時明確顯示，不以隨機或生成內容補值

## 資料說明

行情、公司基本面和新聞透過 Yahoo Finance (`yfinance`) 取得，可能延遲、缺漏或因供應商介面改變而失效。5 分鐘買賣壓力估算是依 K 線漲跌方向分配成交量的代理指標，不等同券商或交易所逐筆資料的實際內外盤分類。完整財報時間序列、除權息事件和正式全市場掃描尚未接入；請勿將本工具視為即時報價或投資建議。

K 線型態以 OHLC 規則辨識，單根型態（例如鎚子、流星）另用近期均線近似趨勢背景；型態可能因行情資料與除權息調整而不同，僅作歷史形狀提示，不代表未來漲跌。跳空型態未納入目前版本。

`market_analysis.py` 和券商 SDK 相關檔案是原有專案內容，這次新增的介面不會取代它們。
